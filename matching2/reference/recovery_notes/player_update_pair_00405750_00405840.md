# Player update pair at 0x00405750 and 0x00405840

## Semantic candidates

`UpdatePlayer_00405750` returns `1` when the active state is zero or when its animation lookup fails. For the active update state, it looks up the player animation, adjusts the player's vertical position using the focus and speed globals, copies the render position to the animation node and its linked children when the node has no own children, copies the node value into the player's collision-radius field, and calls the draw helper. It then advances the embedded frame timer and returns `1`.

`PlayerUpdateCallback_00405840` models the short task callback that forwards its player pointer to `UpdatePlayer_00405750`. The old assembly body was removed from `src/game/player.cpp`; the live region sources now hold readable C++ candidates.

## ABI and context

`layout/ltcg/player_update_00405750.json` groups both functions with a synthetic array caller. The candidate models the main routine receiving its player through EDI and the callback receiving it through ECX before setting up the private EDI receiver. The draw helper at `0x00405AC0` has a register-only ESI input; ordinary C++ does not directly encode that edge, and the context does not prove that LTCG will preserve the needed assignment.

The region sizes, decorated symbols, private register assignments, and emitted bytes have not been built or probed in this batch, so both functions remain unverified C++ candidates.
