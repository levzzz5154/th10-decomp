The full source preserves target-specific behavior rather than copying the
sibling's expressions unchanged. Rejection returns -1 before any quad write or
dependency call unless both flag masks 1 and 2 are set and the primary color's
alpha byte at +2FF is nonzero. The half extents are
`(sprite_width*scale_x)*0.5f` and `(sprite_height*scale_y)*0.5f`. X and Y use
independent three-case switches; selector 3 leaves that axis's shared coordinates
untouched. Both case 2 near edges subtract the corresponding half extent twice.
X additions use position.x, render_offset.x, base_position.x in that order;
Y additions use position.y, render_offset.y, base_position.y, with centered
far Y adding half-height before base Y. The depth sum reads the **true +354
render_offset.z**, then +348 position.z and +33C base_position.z. All four shared
depth coordinates are written, followed by the genuine
`SubmitSpriteQuadMirrored(entity,1)` operation. The exact sibling's +350 depth
quirk is not transferred.

Retail reserves one four-byte stack slot with PUSH ECX. It retains entity in
EAX, uses that local for half-height, loads the incoming manager into ECX at the
tail, pushes mode 1, calls 442AD0, restores the local and returns with RET4. The
rooted ordinary candidate instead loads entity from [ESP+4], reuses that entity
argument slot for half-height, places the rejection block at the end with long
branches, and returns with RET8. Its half-extent arithmetic and ordered source
chains remain a useful complete semantic model, but the entry/lifetime
agreement is different and no instruction-prefix coverage is claimed.

The selected505 source contains no assembly. The retained genuine submitters

No synthetic target caller or new short helper was created to force EAX.

Stock native-LTCG retention explains the measured boundary: `/OPT:REF` discards
an uncalled, unescaped function that is neither entry nor root.
`layout.functions` and documentary `actual_abi` do not retain it or assign
registers. Real references or explicit roots supply retention; the latter pins
the declared public convention. Read-only inspection identified these rules in
`matching2/tools/matching/ltcg_cluster.py`, especially its link roots and MAP
validation, and the existing context documents retention through real calls.
