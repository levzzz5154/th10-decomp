# Enemy acceleration update `0x00407560`: native-LTCG EXACT

Measured 2026-09-27. The entire `0x00407560..0x00407690` region is
**305/305 bytes EXACT** with readable C++, no inline assembly, no masked bytes,
no instruction changes, and no retail bytes supplied to the build.

## Live evidence and behavior

Fresh Ghidra MCP disassembly is recorded in `ghidra_00407560.json`. The caller
at `0x0040639F` tests flag 0x10 at object +0x43C, moves its receiver from EBP
to ESI, then calls this body without a stack argument. This setup is captured
in `ghidra_caller_0040639f.json`. The receiver stays in ESI, and both return
paths are plain RET after removing a 12-byte vector temporary.

The body clears bit 0x10 of +0x43C when the current frame at +0x64C reaches
the duration at +0x670. While active, it advances auxiliary motion at +0x3D8
by the speed-scaled auxiliary acceleration at +0x65C, and adds the speed-scaled
three-component acceleration at +0x664 to velocity at +0x3C0. If either x/y
velocity magnitude exceeds the shared epsilon at 0x470C58, it writes the
atan2(y,x) angle to +0x3E4. It then advances the frame timer regardless of
whether the acceleration has expired: previous/current/elapsed/speed are at
+0x648/+0x64C/+0x650/+0x654.

## Source and compiler context

The vector source is adapted from the already exact EffectAccel update at
0x0041D2C0: `velocity += acceleration * data_00476f78`. The vector constructor,
operator*, and operator+= preserve retail's x87 multiplication order, the
12-byte temporary, the z spill at ESP+8, and FXCH before the x/y additions.
The fabs and atan2 expressions compile to FABS and FPATAN intrinsics, without
extra imported calls. The only emitted helper call is __ftol2 at 0x463B2C.

The timer's normal-speed path reads elapsed through a volatile float view,
then increments the current counter and stores the accumulated elapsed value.
That retains the exact FLD elapsed / INC EDX / FADD shared-one / MOV current /
FSTP elapsed sequence. The other path accumulates the speed and truncates it
through the compiler's x87-input __ftol2 helper. All shared globals are bound
at their retail addresses.

A noinline void member and synthetic receiver-array caller let native LTCG
select ESI for the receiver and emit the observed plain returns. The context
is separate compiler scaffolding and is never selected as recovered code.
The original `enemy_motion_steps.cpp` owns only this selected region; its
other old naked bodies were unselected legacy copies, so the staged source
contains only the recovered target.
