# Animation manager update trampolines at `0x004485D0` and `0x004485E0`

## Disposition

Both wrappers remain naked assembly in
`matching2/msvc/src/unidentified/FUN_004485d0_004485d0.cpp` and
`FUN_004485e0_004485e0.cpp`. An ordinary C++ call cannot express the private
callee entry register: each wrapper receives the manager in `ECX`, copies it
to `EAX`, then tail-jumps into a worker whose machine code reads its manager
from `EAX`. A normal x86 `__fastcall` call would pass its first argument in
`ECX`; it would not reproduce the worker's `EAX` entry. Keeping the move and
tail jump also preserves the callback's return path and the incoming `EDX`.

## Retail bytes and boundaries

Read-only Ghidra disassembly of `th10.exe` gives:

```text
004485d0  mov eax, ecx       ; 8b c1
004485d2  jmp 00448860       ; e9 89 02 00 00
004485d7  int3               ; padding through 004485df

004485e0  mov eax, ecx       ; 8b c1
004485e2  jmp 00448900       ; e9 19 03 00 00
004485e7  int3               ; padding through 004485ef
004485f0  push edi           ; next non-padding code
```

Thus each executable wrapper is seven bytes (`0x004485D0..0x004485D6` and
`0x004485E0..0x004485E6`), followed by `INT3` padding. Ghidra has no function
object at either wrapper address, but reports a data reference to `0x004485D0`
from `GameStateInit` at `0x00445B3A`, and to `0x004485E0` at `0x00445B95`.

## Caller and worker contracts

`GameStateInit` stores each wrapper address in the task callback field at
`+0x08`, stores its `param_1` context at `+0x20`, then registers the task with
`FUN_00449AE0` (primary) or `FUN_00449B70` (secondary). The dispatcher
`FUN_00449C00` loads the task context into `ECX` and calls the callback at
`+0x08` (`0x00449C6D..0x00449C72`). It passes no stack argument. This confirms
the wrapper entry contract: manager/context arrives in `ECX`.

The primary worker at `0x00448860` and secondary worker at `0x00448900` both
begin by copying `EAX` to `EDI` and access manager fields through `EDI`. Each
returns `1` in `EAX` and uses plain `RET`; the wrapper tail-jump lets that
result and return address flow directly back to the dispatcher. Their
machine-code entry is therefore the private `EAX` receiver ABI, irrespective
of Ghidra's autogenerated `__fastcall` labels.

No source body was changed, and no build, probe, or test was run.
