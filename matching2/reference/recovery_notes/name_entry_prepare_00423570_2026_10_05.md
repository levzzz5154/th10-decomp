# 0x00423570 name entry preparation (recovered 2026-10-05)

`src/game/name_entry_prepare_00423570.cpp` compiles to the retail 377 bytes in
the `score_table_insert_00421fa0` cluster, as the real caller of
`ScoreTable::InsertScore` (table in EDI). `make` and `make EXACT=1` pass.

The older 362-byte candidate differed in three places:

* **Selection clamp.** The inlined setter is
  `if (count != 0) selection = item >= count ? count - 1 : item; else selection = item;`.
  With the constant item 0 this leaves retail's three separate stores
  (`dec eax` / `xor eax,eax` / immediate 0). An `if` that clamps the value and
  then stores once merges them.
* **Blank-name test.** `strcmp(name, "        ") != 0`. c2 folds it to
  `repz cmps` over nine bytes with the literal loaded before the count
  (`mov edi,lit; mov ecx,9`). `memcmp(name, lit, 9)` gives the same
  instructions with the two loads swapped, in every spelling tried.
* **Paired global stores.** The stage, the shown stage and the stage table row
  are fields of the address-taken counter block at 0x00474C44 and an indexed
  row of the table at 0x00474788.

The failure path is the `else` of `if (rank >= 0)`, which puts it at the end.
Rig: `build/experiments/name_prepare_423570_claude`.
