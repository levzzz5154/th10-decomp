# 0x00420870 configuration load (recovered 2026-10-05)

`src/app/config_load_00420870.cpp` compiles to the retail 534 bytes in the
`config_load_00420870` cluster. `make` and `make EXACT=1` both pass.

* `GameApp_00420870::LoadConfig(const char* path)`: application object on the
  stack, path in EBX (LTCG private convention, one caller in the entry point).
* The cluster carries the real defaults routine (0x418C40), the archive read
  closure, and body copies of the file writer (size in EDI) and both log
  appenders, so every register contract comes from a visible callee.
* The two "use defaults again" paths share one call to the defaults routine.
  Written as two separate `Append(); InitializeDefaults();` pairs the bytes are
  the same except that `mov edx, config` is scheduled before the `add esp, 4`
  of the log call. With a single call after the branches (`if (!valid)`), the
  flag disappears and the order is retail's.
