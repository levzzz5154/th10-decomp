# 0x00439730 game window creation (recovered 2026-10-05)

`src/platform/window_create_00439730.cpp` compiles to the retail 341 bytes in
the `window_create_00439730` cluster. `make` and `make EXACT=1` pass.

The earlier 308-byte candidate called the Win32 functions through `Iat...`
function-pointer globals. Those are ordinary writable data to the compiler, so
it reloads them for every call. Declared `__declspec(dllimport)`, the import
slots are constant: the three `GetSystemMetrics` calls and the two
`SendMessageA` calls go through ESI, which in turn leaves EBX for the
instance, the compiler's own convention for the single caller. The source is
a plain `__fastcall` function; the context only keeps the instance live
across calls.

`windows_types.hpp` now declares `GetStockObject`, `LoadCursorA`,
`RegisterClassA`, `CreateWindowExA`, `GetSystemMetrics` and `Sleep` as
imports. Rig: `build/experiments/window_create_439730_claude` (binds
`__imp__` symbols to stub pointers with `/ALTERNATENAME`).
