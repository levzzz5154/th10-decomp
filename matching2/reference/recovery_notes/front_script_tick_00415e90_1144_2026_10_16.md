## What moved the count (873 -> 1,144)

Most residuals were the EAX/ECX/EDX rotation of expression temporaries
running one step off from an early point. The rotation is global, so each fix
below also realigned later cases.

- **`CREATE_INTO` resource as a named local** (873 -> 894). Retail allocates
  the resource apart from the rotating temporaries. Exception: the stage
  transition in opcode 20's last branch passes `stage->resource` directly.
- **Opcode 20 replay test as the else arm** (`if (replay_mode != 1) {...}
  else SetInputMode(4);`, 894 -> 906). Retail branches `je` to an out-of-line
  `SetInputMode(4)` block, and the stage 6 and 7 copies then merge as whole
  blocks after an unconditional jump. Explicit `goto`s to shared labels do not
  survive: c2 duplicates the small blocks again.
- **`ScoreState::AddScore` (0x409D90) not visible** (906 -> 909). Retail
  reloads `ecx = &g_globals` before each call, so its compiler did not know
  the callee keeps ECX. Bound as an absolute code symbol instead of compiled.
- **Plain `while` loop** instead of `if (...) do {...} while (...)`. Retail's
  bottom test is the compiler's rotated copy of the top test (forwarded
  `mov eax,edx` copy, `cmp [mem],reg`).
- **0x4492F0 parameter order `(context, id, position)`** (1,017 -> 1,027).
  Retail computes `lea esi,position` before pushing the id: the position is
  the rightmost argument. A stand-in `SetAnimationPosition` with that order is
  bound to 0x4492F0. The previous `(position, context, id)` declaration stays
  in the shared header for the other clusters.
- **Opcode 9 is a bitfield store** (1,027 -> 1,052). `mov eax,esi; xor
  ecx,esi; and ecx,1; xor eax,ecx` is MSVC's 1-bit field insert, not a
  hand-written xor.
- **Opcode 13: resource local assigned before each call, operand inline**
  (`SELECT_PAIR`, 1,052 -> 1,132). Retail evaluates the resource before the
  index for both calls. Index locals, inline resources, or separate second
  locals all score lower (927 to 1,052).
- **Opcode 20 transition slot through a pointer** (`int* transition =
  &stage->transition_animation.value`, 1,142 -> 1,144). The store of 0 then
  stays ahead of the `stage->resource` load.
