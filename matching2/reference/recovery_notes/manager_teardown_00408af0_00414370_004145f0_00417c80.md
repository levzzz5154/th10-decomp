provided declarations for the custom `AnimationManager` flag/resource calls,
scheduler remove/lock context, animation-slot release, vector destructor
iteration, global state, and the stage-transition callers. A native MSVC
13.10.6030 `/LTCG` build linked four source units and placed all four
candidate symbols at their requested VAs. The compiler context itself landed
at `0x00418150` with 108 bytes.

## Cleanup and next dependency

Production asm is restored, `regions.json` is unchanged, and all task-local
candidate sources, cluster layout/context files, object outputs, maps, and
reports were removed. There is no proposal file because no candidate reached
the exact-promotion threshold.

The next useful dependency is an exact compiler/context model for the common
custom ABI rather than another high-level body pass: preserve the observed
register roles for `AnimationManager::SetFlag` and
`MarkResourceForRemoval`, `Scheduler::Remove`, `AnimationSlot_ReleaseRetail`,
and the vector-destructor callback while retaining the original caller
register state. The cluster layout must also account for all maintained
functions owned by `manager_teardown.cpp`, or isolate the context without
temporary source guards. The transition region additionally depends on exact
ABIs for its manager destructor callees and stage-transition helpers.
