## Behavior

The field bounds are the floats at offsets `+0x404`, `+0x408`, `+0x410`, and
`+0x414`. The item half-size is its two size floats multiplied by the global
0.5f at `0x00470B0C`. Strict separation comparisons make edge contact count as
inner-field overlap.

For items outside the inner field, the routine checks the outer rectangle with
the 24.0f margin at `0x00470BE8`, returning 2 when the item remains within that
margin and 0 otherwise. For inner overlap, it returns 0 if the dialogue
manager at `0x0047770C` has a live object at `+0x9EB8`, or if field mode at
`+0x458` is 2, 3, or 4. Otherwise it returns 1. If the timer at `+0x4310` is
below 1, it also invokes `0x00426CF0` with the field-state pointer.

The activation entry remains the existing raw one-stack-argument routine,
which returns with `RET 4`; the C++ code calls it through a matching stdcall
function-pointer type. That activation region remains an assembly dependency.
